
# Secure Password Generator

A Python GUI application to create secure, random passwords based on user preferences. Users can choose the password length and character types, and evaluate the password strength. Built with Tkinter.

## Features
- User-friendly GUI
- Adjustable password length
- Toggle inclusion of uppercase, lowercase, digits, symbols
- Password strength evaluation (Weak/Medium/Strong)
- Copy to clipboard with one click

## Technologies Used
- Python 3
- Tkinter
- string and random modules

## How to Run

1. Install Python 3 if not already installed.
2. Open terminal or command prompt.
3. Navigate to the folder containing the script.
4. Run:
   ```bash
   python password_generator.py
   ```
